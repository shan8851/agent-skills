## Takeaways
- A strong model already does well with a plain prompt on these tasks. The skills' value is in **interaction mechanics** (one gap at a time, time-outs, debrief structure) and **consistency**: answering the actual question first, worked deadlines, never turning "may" into "must", ignoring injected instructions. It isn't new capability.
- v1 → v2 changes to plain-english: answer the user's question first; convert relative deadlines to exact dates with the working shown; "Key points" and "Words explained" optional; sparser quoting.
- rehearse: if the user says start, start (v1 asked and then started anyway).
- check-my-understanding: quote the source in the guiding question without stating the conclusion.
- No factual errors or invented rights in any skill output.
