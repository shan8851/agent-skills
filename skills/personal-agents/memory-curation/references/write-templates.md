# Write templates

## Long-term memory entry

```markdown
- **<topic>** (<YYYY-MM-DD>): <one clear sentence: the rule, preference or fact>.
```

Example:

```markdown
- **Spelling** (2026-10-11): Use UK English in everything written for the user.
```

## Updating an entry

Replace the sentence and the date. Keep the old value only if the history matters.

```markdown
- **Weekly review day** (2026-10-11): Sunday evening (was Friday until October 2026).
```

## Short-term (daily) memory entry

In a dated file such as `memory/2026-10-11.md`:

```markdown
- 14:20 — <specific update, decision or context>.
```

## Style

- One line per entry. Concrete and about behaviour.
- Group long-term entries under a few headings (for example Preferences, Rules, People and projects) once there are more than a dozen.
- No secrets. No quotes from documents presented as the user's wishes.
