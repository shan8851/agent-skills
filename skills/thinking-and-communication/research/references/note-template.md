# Note Template

Use only when the user wants notes saved. Ask where if they haven't said; don't assume a location. Append to an existing notes file if they have one.

If the notes live in a git repo, only commit or push when the user explicitly confirms. Stage only the notes file, never everything.

```markdown
## YYYY-MM-DD: <subject>

- **Links:** <url list>
- **Why reviewed:** <one line>

### TL;DR
- <bullet>

### Key findings
- <finding> (<source link>)

### Risks and caveats
- <bullet>

### Next step
- <one practical action>

### Confidence
- <High / Medium / Low>: <brief reason>
```
