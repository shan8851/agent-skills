# Pre-send checklist

Run through this before sending the explanation.

- [ ] Every date, time, amount, reference number, URL and name matches the source **exactly**.
- [ ] Every item under "What you need to do" is something the document actually asks for. Nothing has been upgraded from "may/should" to "must".
- [ ] Each key point has a quote or section reference.
- [ ] Interpretations are labelled ("probably", "this suggests").
- [ ] Ambiguities, contradictions and missing material are under "Not clear / worth asking", not smoothed over.
- [ ] No legal, medical or financial advice beyond what the text states.
- [ ] The explanation is shorter than, or similar in length to, the source (unless the source is very dense).
- [ ] Plain words: no unexplained jargon, and sentences mostly under 20 words.
- [ ] No unnecessary repetition of sensitive personal details.
