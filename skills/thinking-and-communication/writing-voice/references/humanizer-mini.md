# Humaniser Mini Pass

A light clean-up pass after drafting in voice.

## Purpose

Remove obvious AI-style residue without stripping personality.

## Keep this pass small

Only these checks by default:
1. Lists to prose where prose reads better.
2. Emoji clean-up.
3. Em dash clean-up, unless the voice profile says otherwise.
4. Title-case headings, when they clash with the writer's voice.
5. Cut preamble or recap sentences that only announce the point.

## Rules

- Don't rewrite for generic neutrality.
- Don't remove sharp opinions, self-awareness or natural rhythm.
- Keep phrasing that already sounds like the writer.
- If a list is clearer as a list, keep it.
- If the profile or samples show the writer uses something (dashes, emoji, headings), keep it.
- If a sentence has personality and precision, leave it alone.

## Quick QA

- Still sounds like the writer's samples.
- Reads naturally out loud.
- No obvious AI formatting residue.
- Nothing sanded down into bland "professional" copy.
